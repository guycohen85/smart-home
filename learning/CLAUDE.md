# Learning workspace

This directory is a `/teach` workspace. Read `NOTES.md` for the user's teaching preferences before creating lessons.

## Index page

Keep `index.html` (in this directory) as the table of contents for the workspace:

- Link every lesson in `lessons/` in numeric order, and every document in `reference/`.
- Update it in the same turn whenever a lesson or reference document is created, renamed, or retitled.
- Use `assets/style.css` and the existing `.toc` markup in `index.html`; Hebrew, RTL.
