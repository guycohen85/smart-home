רפרנס מהיר

דף עזר: אוטומציות

מבנה, תחביר, ודרך דיבוג. מקור: Automation basics ו-Automation YAML.

המבנה

מתיtriggers

רגע שקורה. מתחיל ריצה.

רק אםconditions

מצב שנבדק פעם אחת, ברגע הטריגר.

אזactions

מה הבית עושה.

כלל האצבע: אם זה "קרה", זה טריגר. אם זה "נכון עכשיו", זה תנאי. HA לא מחכה שתנאי יתקיים.

שלד YAML (תחביר נוכחי)

alias: שם האוטומציה
triggers:
  - trigger: state          # לא platform: (תחביר ישן)
    entity_id: switch.boiler
    to: "on"
    for: "01:00:00"         # המצב חייב להישאר לאורך כל הזמן
conditions: []              # אופציונלי
actions:
  - action: switch.turn_off # לא service: (תחביר ישן)
    target:
      entity_id: switch.boiler
  - action: persistent_notification.create
    data:
      message: טקסט ההתראה
mode: single

התראה עם כפתורים (שיעור 5)

שולחים ← לוחצים (event) ← מחכים (wait_for_trigger) ← מחליטים (wait.trigger). מקור: Actionable notifications.

- variables:
    action_off: "{{ 'BOILER_OFF_' ~ context.id }}"   # מזהה ייחודי לכל ריצה
- action: notify.mobile_app_<device_id>
  data:
    message: לכבות?
    data:
      actions:
        - action: "{{ action_off }}"
          title: כבה
- wait_for_trigger:
    - trigger: event
      event_type: mobile_app_notification_action
      event_data:
        action: "{{ action_off }}"
      id: "off"
  timeout:
    minutes: 10
- if:
    - condition: template
      value_template: "{{ wait.trigger is none or wait.trigger.id == 'off' }}"
  then: [...]
משתנהערך
wait.triggerהטריגר שהעיר את ה-wait, או none אם הזמן נגמר
wait.trigger.idה-id שנתת לטריגר ב-wait
wait.remainingכמה זמן נשאר עד ה-timeout (מקור)

סקריפטים וסצנות (שיעור 6)

כליעונה על
אוטומציהמתי: טריגר + תנאים
סקריפטמה: רצף צעדים, עם פרמטרים (fields) וערך חזרה
סצנהאיך הבית נראה: רשימת מצבים, בלי צעדים ובלי "כבוי"
# בסקריפט: להחזיר תשובה (חייב להיות מפתח: ערך)
- variables:
    result:
      answer: "{{ 'timeout' if wait.trigger is none else wait.trigger.id }}"
- stop: Got an answer
  response_variable: result

# באוטומציה: לקרוא ישירות ולקבל את התשובה
- action: script.ask_phone        # לא script.turn_on!
  data:
    message: לכבות?
  response_variable: reply        # reply.answer

# צילום מצב והחזרה אליו
- action: scene.create
  data:
    scene_id: before
    snapshot_entities: [light.salon]
- action: scene.turn_on
  target:
    entity_id: scene.before

מקורות: Scripts · stop + response_variable · Scenes.

מלכודות ידועות

מלכודתמה קורה
החלפה בין טריגר לתנאיהאוטומציה רצה ברגע הלא נכון, התנאי נכשל, ואין ריצה נוספת.
שדה for ו-restartהשעון מתאפס ב-restart או ב-reload (מקור). בעייתי ל-For ארוך אצל לקוחות שמתעדכנים מרחוק.
עריכה ידנית של automations.yamlהקובץ מנוהל על ידי ה-UI. לא לערוך ידנית (מקור).
בן בית בלי person עם טלפוןלא נספר ב-zone.home. "אין אף אחד בבית" יהיה נכון גם כשהוא בבית.
הרשאת מיקום לא על "Allow all the time"המיקום לא מתעדכן ברקע, והבית חושב שהלקוח עדיין בבית.
Set state ב-Developer toolsמשנה רק את מה ש-HA רואה, ונדרס בעדכון הבא. טוב לבדיקות קצרות בלבד.
מילים כמו off בלי מירכאותב-YAML הן הופכות לבוליאני. תמיד "on" / "off".
כפתור בהתראה בלי מזהה ייחודילחיצה אחת מעירה כל wait שמחכה לאותו מזהה, גם באוטומציה אחרת.
לחיצה אחרי שה-wait הסתייםהאירוע נורה, אבל אף אחד לא מקשיב. כלום לא קורה.
יותר מ-3 כפתוריםאנדרואיד מציג עד 3. באייפון בערך 10.
הכפתור Run actionsמריץ רק פעולות ומדלג על טריגרים ותנאים. לא בודק לוגיקה.
מילים כמו yes/no בלי מירכאותאותה מלכודת כמו off: הופכות ל-true/false.
קריאה ל-script.turn_on במקום לסקריפט ישירותלא מחכה לסקריפט ולא מחזיר תשובה. ה-response_variable נשאר ריק.
סקריפט ב-mode: single (ברירת המחדל)קריאה שנייה בזמן שהראשונה רצה לא מתבצעת. לסקריפט "שאל" צריך parallel.
שם סקריפט בעבריתה-ID נגזר מהשם. לתת שם באנגלית בשמירה הראשונה.
לצפות שסצנה "תתבטל"לסצנה אין מצב כבוי. חוזרים עם סצנה אחרת או עם scene.create לפני השינוי.

דיבוג: "האוטומציה לא עבדה"

  1. פתח Traces (עורך האוטומציה ← שלוש נקודות). כברירת מחדל נשמרות 5 ריצות אחרונות (מקור).
  2. אין ריצה בכלל? הבעיה בטריגר: הוא לא קרה, או שה-For נקטע.
  3. יש ריצה שנעצרה? לחץ על צומת התנאי וראה איזה ערך נכשל.
  4. לחצו על כפתור בהתראה ולא קרה כלום? Developer tools ← Events, האזנה ל-mobile_app_notification_action.
  5. הפעולה רצה ולא קרה כלום? בדוק את המכשיר עצמו: האם הוא זמין (לא unavailable)?
