דף עזר: Apps ו-HACS

מה רץ בתוך HA ומה לצידו, איפה הקבצים, ואיך מתקינים. מקור: Apps, Common tasks: HA OS ו-תיעוד HACS.

שינוי שם מה שנקרא פעם Add-on נקרא היום App. התפריט: Settings → Apps. קיים רק ב-HA OS.

שלוש רמות אמון

סוגאיפה רץמי בודקאצל לקוח
אינטגרציה רשמיתבתוך HAצוות HAכן
App ממאגר רשמילצד HAצוות HAכן
App ממאגר צד שלישילצד HAאף אחד: "בלי ערובה לאיכות או לאבטחה"רק בחריג
אינטגרציה מותאמת (כולל כל מה שמגיע מ-HACS)בתוך HAאף אחד: "עלולה לפגוע ביציבות"רק בחריג

זוג נפוץ: App היא השרת, ואינטגרציה היא הלקוח. למשל Mosquitto (App) ואינטגרציית MQTT. בלי האינטגרציה, HA לא רואה את המכשירים.

הוספת מאגר Apps של צד שלישי

  1. עבור ל-Settings → Apps → Install app ← שלוש נקודות ← Repositories.
  2. הדבק את כתובת ה-git (ב-GitHub: Code ← HTTPS) ולחץ Add.
  3. אם המאגר לא מופיע, רענן את הדפדפן. אם עדיין לא, בדוק ב-Settings → System → Logs.

התקנת HACS ב-HA OS

מאגרhacs/addons

להוסיף את https://github.com/hacs/addons

אפליקציהGet HACS

להתקין, להפעיל, ולבצע את מה שכתוב בלוג

אתחולrestart

לאתחל את HA ולנקות מטמון בדפדפן

אינטגרציהAdd integration

HACS, עם device code ב-github.com/login/device

דרישות: HA 2024.4.1 ומעלה, התקנה נתמכת, גישה לקבצים וללוג, אינטרנט בלי חסימה של GitHub ו-Cloudflare, וחשבון GitHub. HACS הוא אינטגרציה מותאמת ולא App.

רכיב HACS אצל לקוח: שאלות לפני שמכניסים

טיוטה. המדיניות של OneHome עוד לא הוחלטה (ראו שיעור 8).

  1. למה הוא נחוץ? האם אינטגרציה רשמית או Alert ואוטומציות פותרים את אותו צורך?
  2. מי מתחזק אותו, ומתי היה העדכון האחרון?
  3. מה קורה ללקוח אם הרכיב נשבר בעדכון של HA, ומה תוכנית החלופה?
  4. האם הוא נבדק קודם בבית של גיא, לפחות לאורך עדכון HA אחד?
  5. האם הוא רשום ברשימת החריגים של אותו לקוח?

מלכודות

מה קרהלמה
אין Settings → Appsזו לא התקנת HA OS. Apps קיימות רק שם.
