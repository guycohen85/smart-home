דף עזר: בית התבנית ו-golden backup

איך מקימים התקנה נקייה, מה נכנס אליה, ואיך מגבים אותה. מקור: התקנה ב-Windows, התקנה ב-macOS, Onboarding, גיבוי ושחזור, ו-הצ'ק-ליסט.

הכלל רכיבים עוברים בכיוון אחד: הבית שלך ← בית התבנית ← golden backup ← לקוח. לעולם לא מגבים את הבית שלך כדי לשחזר אצל לקוח.

שני בתים באותה רשת

  • כתובת homeassistant.local עלולה להוביל לבית שלך. פותחים את התבנית לפי IP: http://<IP>:8123.
  • כתובת ה-IP נמצאת ברשימת המכשירים בראוטר.
  • שם המכונה: משנים ל-onehome-template ב-Settings → System → Network (לפי הפורום, לא אומת בתיעוד).

גיבוי

  • מסלול בתפריט: Settings → System → Backups → Backup now → Manual backup.
  • גיבוי מלא כולל את התיקיות config, share, addons, ssl ו-media.
  • שם הקובץ: onehome-template_<תאריך>_ha-<גרסה>. הגרסה מופיעה ב-Settings → About.
  • ערכת חירום (Emergency kit): שומרים במנהל הסיסמאות עם שם הגיבוי. בלעדיה אי אפשר לשחזר גיבוי מוצפן.

שחזור: עובדות שחשובות אצל לקוח

  • במסך ההגדרה הראשונית אפשר לבחור Upload backup במקום התקנה חדשה.
  • השחזור דורס את המערכת. מתחברים עם המשתמש והסיסמה שהיו בזמן הגיבוי.
  • צריך את מפתח ההצפנה מערכת החירום.
  • למכשיר היעד צריך להיות יותר מקום פנוי מאשר למכשיר המקור.
  • בהתקנה גדולה השחזור יכול לקחת כ-45 דקות. לא מרעננים את הדף.
  • גרסה: לפי הצ'ק-ליסט, גרסת HA בתבנית צריכה להיות זהה לזו של הלקוח או ישנה ממנה. לא מופיע בתיעוד הרשמי, ובודקים בשיעור 12.
