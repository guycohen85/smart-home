דף עזר: Blueprints

איך הופכים אוטומציה שעובדת לקובץ אחד שמשרת את כל הלקוחות. מקור: Tutorial, Schema, Selectors, Using blueprints.

הכלל הקובץ נכנס לתבנית. האוטומציה שנוצרת ממנו נוצרת רק אצל הלקוח, כי רק שם יש מכשירים למלא בחורים.

שלד של קובץ

blueprint:
  name: "OneHome: ..."          # חובה
  domain: automation             # חובה (automation / script / template)
  description: ...
  author: OneHome
  input:
    my_input:
      name: ...
      default: ...               # אופציונלי. בלי default השדה חובה
      selector: { entity: { filter: [ { domain: switch } ] } }

variables:
  my_var: !input my_input        # רק כך אפשר להשתמש ב-input בתוך {{ }}

triggers:
  - trigger: state
    entity_id: !input my_input
# ... conditions / actions כמו באוטומציה רגילה

הבוררים שבשימוש

בוררערך שמתקבלשימוש אצלנו
בורר entity עם filter: domainמזהה ישות, למשל switch.boilerהדוד
בורר device עם filter: integration: mobile_appמזהה מכשיר (device ID)הטלפון, לשליחה בפעולת מכשיר
בורר durationמבנה כמו {hours: 2}, ומתאים ישר ל-for ול-timeoutזמן דלוק, זמן לתשובה
בורר targetמבנה עם entity, device או areaעוד לא. מתאים ל"כל האורות בסלון"

זהירות עם סינון לפי integration: הוא לא אמין במכשירים שמתחברים דרך כמה אינטגרציות, כמו Zigbee או Matter. שם משלבים סינון לפי יצרן או דגם (מקור).

שליחת התראה לטלפון מתוך Blueprint

- domain: mobile_app
  type: notify
  device_id: !input phone
  message: "..."
  data:                          # כפתורים עוברים כמו ב-notify רגיל
    actions:
      - action: "{{ action_off }}"
        title: כבה

מלכודות

  • כתיבת !input בתוך {{ }} לא עובדת. קודם מעבירים אותו ל-variables.
  • תיקון בקובץ מגיע לכל האוטומציות באותו HA בטעינה הבאה. לקוחות קיימים לא מקבלים אותו מגיבוי חדש: צריך להחליף אצלם את הקובץ. זו הסיבה לנהל Blueprints ב-git.
  • האפשרות Take control היא חד-כיוונית, ומנתקת את הלקוח מתיקונים. עדיף להוסיף input עם ברירת מחדל.
  • הפעולה Re-import דורסת את הקובץ. אם הגרסה החדשה לא תואמת, אוטומציות קיימות עלולות להישבר.
  • אוטומציה ישנה שעושה אותו דבר: משביתים אותה לפני הבדיקה, אחרת יש שתי שאלות על אותו דוד.
  • מקטעי input (sections) דורשים min_version: 2024.6.0 בבלוק homeassistant.
